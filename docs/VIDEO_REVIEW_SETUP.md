# 영상 등록 · 분석 · 검수 · 게시

## 화면

- `/video-register.html`: 영상 등록 → AI 분석 → 분석 목록 → 기존 경기 연결·해제 순서. 영상 등록만으로 AI를 호출하지 않습니다.
- `/feedback-review.html?analysis_id=1`: 기존 분석 결과를 여는 관리자 검수 화면. 왼쪽 원본 영상, 오른쪽 작은 시간·코멘트 입력란으로 구성합니다. 요약·시간·코멘트 수정, 잘못된 장면 삭제·추가, 임시 저장, 검수 완료를 제공합니다. 새 분석 입력 폼은 없습니다.
- `/video.html`: 경기 영상 / 분석 결과 / 하이라이트 순서의 탭. 분석 결과에서는 영상을 선택하고 검수 완료된 시간·짧은 코멘트를 확인합니다. 시간을 누르면 원본 영상의 해당 장면으로 이동합니다. 하이라이트 파일 생성은 아직 포함하지 않습니다.
- 기존 `/feedback.html?analysis_id=...` 주소는 검수 화면으로, 분석 ID가 없는 기존 분석 폼 주소는 관리자 화면의 AI 분석 영역으로 이동합니다.

## 저장·접근 정책

- 기존 `video_analysis.feedback` JSON의 `review`에 검수 내용을 저장합니다. 스키마 추가·초기화는 없습니다. AI 원문과 원본 `video_event`는 보존합니다.
- 임시 저장은 검수 초안만 갱신합니다. 게시 중인 내용이 있으면 선수 화면에는 이전 게시본을 유지합니다.
- 검수 완료 시 현재 요약·시간·코멘트를 게시본으로 저장합니다. 게시본이 없는 분석은 회원 조회 API에서 반환하지 않습니다.
- 관리자 목록·상세·수정 API는 관리자 권한을 검증하며 수정·게시에는 CSRF 검사도 적용합니다. 동의한 로그인 회원과 선수 회원은 게시본만 조회할 수 있습니다.
- 수정은 테스트 DB에서만 허용하며 행 잠금과 revision 검사로 다른 창의 수정 덮어쓰기를 막습니다. 원본 DB 전환은 별도 승인 후 진행합니다.
- 검수 페이지에서는 AI를 다시 호출하지 않습니다. 기존 영상 삭제 시의 분석 자료 삭제 규칙은 유지합니다.

## 변경 파일

- `src/db/feedback_store.py`, `src/api/youtube_feedback.py`: 검수 저장·게시와 공개 가능한 게시본만 반환하는 API.
- `main.py`: 관리자 검수 페이지 보호 및 기존 분석 화면 주소 이동.
- `public/video-register.html`, `video-register.js`, `video-analysis-form.js`: 등록·분석 분리와 목록의 검수 페이지 연결.
- `public/feedback-review.html`, `feedback-review.js`, `feedback-review.css`: 간결한 검수 화면.
- `public/video.html`, `video.js`, `video-published.js`, `video-review-layout.css`: 회원·선수의 게시 결과 조회와 시간 이동.
- `tests/test_feedback_review.py`, `tests/browser_feedback_review.cjs`: 초안 비공개·게시본 보존·권한·충돌·시간 검증과 화면 동작 검증.

## 확인 결과

- 전체 단위 테스트 100개: 94개 통과, 실제 DB 관련 6개 제외.
- 모의 API 브라우저 테스트: 분리된 메뉴 순서, 수정·임시 저장·게시, 선수용 시간·코멘트, 장면 이동, 모바일 가로 넘침 없음 확인.
- 기존 영상 등록·연결·비회원 및 회원 권한, 영상 목록의 지연·서버 오류 처리 브라우저 테스트 통과.
- 실제 테스트 DB는 읽기 전용으로 조회했습니다. 분석 ID 1의 원래 장면 13개가 보존돼 있으며 게시본은 없습니다. 실제 검수 완료·게시 클릭은 사용자가 수행합니다.
- 추가 AI 호출·원본 DB 변경·커밋·Push 없음.
