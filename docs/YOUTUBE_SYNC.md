# WGH YouTube 자동 등록 — 테스트 DB 단계

채널: https://www.youtube.com/@yuni_andv5909
채널 ID: `UCmz846rJsnMWyimoMhgyEow`

- 제목에 `WGH`(대소문자 무관) **또는** `은평`이 있고, 유효한 `YYYY-MM-DD` 날짜가 정확히 하나 있는 영상만 등록합니다.
- 해당 날짜를 경기 날짜로 사용합니다. 업로드 날짜를 대신 넣지 않습니다.
- 기존 영상의 제목·날짜·경기 연결은 수정하지 않습니다. 새 영상의 경기 연결은 비워 두고 기존 관리자 화면에서 지정합니다.
- 영상 ID 고유 키로 중복 등록을 막습니다. 처리한 영상 ID는 `.wgh-sync/youtube-state.json`에도 보관하여 홈페이지에서 삭제한 영상을 다시 넣지 않습니다. 이력 파일을 지우면 이 보호가 사라지므로 보존하세요. 자동화가 한 번도 확인하지 못한 과거 삭제 영상은 구분할 수 없습니다.
- 현재 공개 피드에 표시되는 최근 영상만 확인합니다. 오래된 영상 전체 수집, 장기 중단 중 피드에서 밀려난 영상의 복구는 포함하지 않습니다. 그 경우 수동 등록이나 추후 업로드 목록 API 보완이 필요합니다.
- 기존 테이블을 변경하지 않습니다. 현재 단계의 실제 등록은 `futsaldb_test`에서만 허용합니다. 원본 DB에서는 실패하도록 막았습니다.
- AI 호출·영상 다운로드·하이라이트 편집은 이 단계에 포함하지 않습니다.

프로젝트 폴더에서 읽기 전용 미리 보기:

```powershell
cd C:\workspace\futsal_match
.\.venv\Scripts\python.exe youtube_sync.py
```

미리 보기는 네트워크로 공개 피드만 읽으며 DB 연결·등록·이력 저장을 하지 않습니다. `skip_reason`이 비어 있는 영상이 등록 후보입니다. 중복 여부는 실제 등록 시 DB에서 검사합니다.

등록 대상 확인 후 테스트 DB에 한 번 등록:

```powershell
.\.venv\Scripts\python.exe youtube_sync.py --apply
```

300초마다 자동 확인하려면 별도 터미널에서:

```powershell
.\.venv\Scripts\python.exe youtube_sync.py --apply --watch
```

이 명령은 현재 공개 피드의 기존 영상도 조건에 맞으면 등록합니다. 터미널을 닫거나 Ctrl+C로 중지하면 자동 확인도 멈춥니다. FastAPI 실행만으로 자동 시작하지 않으며 윈도우 예약 작업·서비스도 설치하지 않습니다. 두 동기화 프로세스의 동시 실행은 잠금으로 차단합니다.

`.env`는 프로젝트 위치에서 읽지만 PowerShell의 기존 환경변수 값이 우선합니다. 원본 DB로 복귀할 때 `.env`와 현재 PowerShell 환경변수를 함께 확인해야 합니다. DB·처리 이력 오류가 발생하면 등록을 중단하고 원인을 확인한 뒤 다시 실행하세요. DB 커밋 후 이력 저장 실패 시 재실행하면 고유 키 검사로 중복을 방지합니다.

첫 확인 결과: 현재 읽은 공개 피드에서는 합의한 `YYYY-MM-DD` 형식을 포함한 등록 후보가 없었습니다. 예전 제목의 `25.03.30` 같은 날짜는 임의 해석하지 않습니다.

자동 등록 시 YYYY-MM-DD는 경기 날짜에 저장하고 홈페이지 영상 제목에서는 제거합니다. 예: 2026-03-30 은평vs다산2 → 날짜 2026-03-30, 제목 은평vs다산2. 유튜브 원본 제목과 제목의 다른 숫자는 유지합니다. 기존 등록 영상의 제목은 자동 동기화로 덮어쓰지 않습니다.

## 현재 활성 예약과 최신 등록 조건
- Codex 이 대화에 연결된 예약 WGH 경기영상 자동 등록(id: wgh): 매주 수요일·토요일 한국 시간 오후 6시. 각 예약에서 youtube_sync.py --apply를 한 번 실행하며 --watch는 실행하지 않습니다.
- 최신 키워드는 WGH(대소문자 무관), 은평, 친선경기 중 하나입니다. 제목의 YYYY-MM-DD 날짜를 match_date에 저장하고 홈페이지 제목에서는 제거합니다.
- 공개 RSS 피드 실패 시 채널 ID를 검증한 공개 동영상 탭으로 확인합니다. 일부 공개 자동 발견은 아직 지원하지 않습니다. 채널 페이지 구성 변경이나 두 조회 경로 모두 실패하면 등록하지 않습니다.
- 수동 등록 영상도 youtube_id 고유 키로 중복 제외합니다. 처리한 영상의 홈페이지 삭제 후 재등록 방지는 .wgh-sync 이력 보존에 의존합니다.
- 이 PC의 프로젝트와 MySQL을 사용하므로 예약 시간에 PC·Codex 앱·MySQL이 실행 중이어야 하며 필요한 파일·네트워크·DB 접근 권한이 있어야 합니다. FastAPI는 등록 결과를 보여 주는 데 사용합니다.
- 현재는 테스트 DB만 허용합니다. 원본 DB 복귀 및 운영 서버 예약 전환은 별도 승인 후 진행합니다. 프로그램의 --watch 옵션은 수동 도구로 남아 있으나 현재 예약에서는 사용하지 않습니다.
- 설정 시 실제 실행 결과 신규 0건, 기존 처리 등 제외 8건. 예약이 없어도 홈페이지 수동 등록은 계속 가능합니다.
