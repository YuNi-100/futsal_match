# WGH 클럽 홈페이지

K리그의 경기·기록·영상·소식 중심 정보 구성을 참고해 만든 WGH의 별도 프런트엔드입니다. K리그의 화면을 직접 복제하거나 공식 로고·기사를 사용하지 않았습니다. 기존 WGH 로고와 구장 이미지는 `public/images`에서 재사용합니다.

## 열기

기존 FastAPI를 저장소 최상위에서 실행하고 `http://localhost:8000/club/`에 접속합니다.

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

기존 `/`, `/video.html`, `/feedback.html`, `/article.html`과 FastAPI·MySQL 코드는 그대로 유지합니다. 홈페이지를 기본 경로로 전환하지 않았습니다. 서버 실행에 필요한 의존성·DB 환경은 저장소 루트 README를 따릅니다.

## 데이터 모드

`config.js`의 `mode`:

- `auto`: `/api`가 정상 응답하면 기존 읽기 API를 사용합니다. `/api`가 404 또는 405인 정적 서버에서만 예시 모드로 전환합니다.
- `live`: 기존 FastAPI 데이터만 사용합니다. 연결 실패 시 오류를 표시합니다.
- `demo`: 가상 예시 데이터로 동작합니다. 변경 사항은 현재 브라우저의 `localStorage`에만 저장합니다. 다른 기기와 공유되지 않습니다.

서버의 목록 조회가 실패할 때 실제·가상 데이터를 섞지 않습니다. 사용자가 오류 화면에서 '예시 모드로 둘러보기'를 직접 선택할 수 있습니다. 브라우저 저장 실패도 표시합니다. 실제 운영 기록을 예시 모드에 저장하지 마세요.

## 동작

- 홈: 최근 경기, 다음 경기, 팀 전적, 득점·도움·출전 순위, 선수 소개, 영상·소식
- 경기: 검색, 연도·승무패 필터, 예정 일정, 월간 캘린더, 경기 상세, ICS 일정 다운로드
- 선수: 포지션 필터, 누적 기록, 예시 데이터의 선수별 득점 경기 연결
- 영상: 사이트 내부 YouTube 임베드, 분류, 12초 전술 애니메이션과 타임스탬프 시연
- 예시 편집: 경기·일정·선수·유튜브·소식 추가, 일부 항목 수정·삭제, JSON 내보내기, 초기화
- 숫자 날짜 `20261018` → `2026-10-18`, 숫자 시간 `2000` → `20:00`

## 실제 API에서 제공하지 않는 정보

기존 API에 선수별 경기 연결, 경기별 득점자, 공지 API가 없어 실제 모드에서는 그 정보를 추정하지 않습니다. 설명 상태를 표시합니다. 영상의 `match_id`가 있으면 경기 상세와 연결합니다. 기존 API는 모든 YouTube 영상을 원본 경기로 분류하므로 새 화면도 동일하게 처리합니다.

예시의 경기·선수·상대팀·일정·소식은 전부 가상입니다. 선수 이미지는 사진 대신 유니폼 일러스트입니다. 전술 애니메이션은 실제 경기 영상이나 AI 분석 결과가 아닙니다.

새 로그인·관리자 인증, 실제 AI 호출, 서버 데이터 변경, DB 이전은 추가하지 않았습니다. 실제 모드는 읽기 API만 호출하며 등록·분석은 기존 관리 화면으로 연결합니다. 공개 운영에 필요한 서버 인증·권한 검사는 별도 작업입니다.

## 검증

JavaScript 구문 검사와 DOM 에뮬레이션으로 라우팅·필터·상세 연결·예시 저장·날짜/시간·유튜브 URL 검증·API 실패 처리를 확인했습니다. 테스트 환경에서 실제 MySQL·외부 AI 호출·YouTube 재생·브라우저 화면 배치·모바일 실기기는 검증하지 않았습니다.
